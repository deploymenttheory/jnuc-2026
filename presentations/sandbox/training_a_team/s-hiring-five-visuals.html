Slide 16 - Hiring for the new world (five visual treatments)

Gordon: "the content is right, it's just a bit boring. Can you come up with 5 different visuals for this slide. Completely different from each other." The content is unchanged in every option - six skills to hunt for, three market facts and two pieces of advice - only the presentation changes. Gave the slide a stable id, #s-hiring, and wrapped the shipped two-card layout as option A. Compare the current live slide.

Option B - Chip cluster

The six skills as sized chips in a wrapped cluster rather than a vertical list - Terraform and Git CLI get bigger chips, since the notes single them out as the strongest signals, the other four sit at a smaller consistent size. Market facts run as a plain stacked list; the two pieces of advice are pulled out as their own accent-bordered callouts rather than sitting inside the same bullet list as the facts. Pick this if the room should scan the skills like a tag board rather than read them top to bottom.

Option C - Scorecard

    
A real ruled table - skill, why it matters - in a bordered card, reading like an interview rubric rather than a bullet list. No invented rating column: an earlier pass added a "signal strength" dot rating per skill, which was dropped because the source never ranks these skills against each other and inventing one would misrepresent it. Market signals and advice sit in a footer strip below the table. Pick this if the room should be able to scan it like a real hiring scorecard.

Option D - Two routes

    
A branching "two routes" diagram - one statement forks into "hire externally" (screen for the six skills) and "promote internally" (the market case for it, from the same market facts and advice as every other option). Deliberately not a Venn/overlap diagram: an earlier idea had the six skills sitting in the overlap between "Mac admin today" and "Terraform/DevOps" circles, which would have implied Mac admins already have these skills - something the source never claims. This version regroups the exact same content under a decision framing instead. Pick this if the room should leave thinking about which path to take, not just what to look for.

Option E - Stepping bands

    
Migrating_an_instance's s08 wave-workflow pattern, reused here for hiring: six full-width numbered rows for the skills, then a closing band splitting cleanly into the market facts on the left and the two pieces of advice on the right. Pick this if the room has already seen slide 9 or 11's bands and the visual language should stay consistent across the deck.

Option F - Icon board

    
A 3x2 pictogram grid - one simple line-drawn mark per skill (this deck has no icon sprite, so these are hand-drawn geometric glyphs: a hexagon for Terraform, a branch glyph for Git, a terminal for scripting, a refresh loop for CI/CD, a plug pair for API/REST, a star for open source), each paired with the skill name and its one-line reason. Market signals and advice sit in a footer strip below, same as options C and E. Pick this if the room responds best to a picture per item rather than a shape per row.
