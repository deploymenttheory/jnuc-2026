Slide 17 - growing pains, how the slide displays

Joseph asked for the pivot line to go - "It got out of hand. The pivot: shared modules own the configuration; thin per-instance roots own only what genuinely differs." - and for options on what is left. That removal is already in the deck and in all four renders below, along with its TODO chip, which has moved onto the code block so the reminder is not lost. What is left is a title, one lead sentence and one HCL block, and these are four different ways to hold the slide with only those pieces. Each render is the real #s-pivot section with one option's CSS layered on top; A is exactly what the deck ships today. C and D also need markup, so their wrappers already sit inside the section, hidden by a single deck rule, and the CSS here only flips which wrapper shows.

Option A - one column, lead over code live now

The tidy version of what the removal left behind, and what ships from this PR. The lead keeps its full size at the top; under it the conditional runs out to the same right-hand edge as the lead so the two read as one column, and the code sits a step up the type scale from the deck default so the block carries the lower two thirds of the slide on its own. The TODO chip sits under the code, clear of the timeline. Pick this if the slide is a supporting beat that Joseph talks over rather than a moment the room is meant to stop at - it is the least emphatic of the four and the only one that needs no new markup at all.

Option B - the code is the slide, "everywhere" is the punchline

    
The lead drops to a two-line kicker in muted text above the block, and everything it gives up goes into the code, which fills the width at heading size. Option C - the code beside what the URL decided

    
Two columns. The conditional keeps the left, and the right holds a stack under the heading "What one URL decided", so the spread is visible rather than just asserted: whether a resource existed at all, with count = local.is_staging ? 0 : 1 under it, and deployment behaviour, inferred from a URL everywhere the two instances had to differ.
