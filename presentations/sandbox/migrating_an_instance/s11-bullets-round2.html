Slide 12 - tools and helpers, plain bullets

Round one offered four visual treatments of the right-hand points and Joseph turned all of them down: what he wants is nice, easily separated bullet points. Those four wrappers and their CSS are gone from the deck in this PR, so the right-hand column is plain markup again - one list, four items, each a name over one line - and the wording is untouched. Every render below is the real slide with only the option's CSS on top; the pipeline diagram on the left is the same in all four.

ABCD

Option A - the dashed list live now

The deck as it ships from this PR. Four points separated by a wide gap, each with a short accent dash in the left margin, the name in monospace at title size and the line below it in body text. The dash turns danger-coloured on the rejected fourth point. Nothing is injected for this option.

Option B - hairline between each point

    
The dashes come off and a hairline rule runs between the points instead, so each one is a band of its own reaching the full width of the column. The name keeps the accent colour and the line sits under it in body text with a little more air. The quietest of the three, and the one that leaves the most room if a line ever grows.

    

    
CSS on top of the deck

  


  

    
Option C - each point on its own panel

    
Each point sits on the deck's navy card surface, no border, with the name and its line side by side rather than stacked. The name is in a fixed-width left column so all four lines start on the same edge, which gives the column a spine the other two do not have. The name drops to body size to fit the column.

    

    
CSS on top of the deck

  


  

    
Option D - a numbered list

    
The dash becomes a number, 1 to 4, in monospace in the accent colour in a gutter down the left. The name moves out of monospace into the deck's display face in bold, with the line beneath it as before. The fourth number turns danger-coloured along with its name, so the rejected flag reads as the odd one out without a strike-through.
