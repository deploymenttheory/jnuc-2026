# Jamf Pro UI icons

Icons scraped from the Jamf Pro web UI (Jamf's "Nebula" design-system icon set) for use in
JNUC 2026 slides. Everything here is generated by `scrape_jamf_icons.py`; open
`contact-sheet.html` to browse and filter the whole set.

| Folder / file        | What it is                                                                                          | Count |
|----------------------|-----------------------------------------------------------------------------------------------------|------:|
| `font/`              | Every glyph of the `jamf-icons.woff` icon font, as 24×24 SVGs, named by the font's own glyph names (`cog-8-tooth-outline`, `blueprints-outline`, …). The complete set: 412 outline, 288 solid, 5 branded, 1 android. | 706 |
| `inline/`            | The inline SVG library that the Angular `<jamf-icon>` component actually renders (the exact original path markup). Named by matching against the font (see *Naming* below). | 130 |
| `settings/`          | The coloured 32×32 tiles from **Settings → Display icons**, one per settings card (`ldap-servers.svg`, `api-roles-and-clients.svg`, …), rebuilt with the same icon, colour tokens, padding and radius as the UI. | 81 |
| `assets/`            | Static SVGs served from `/assets/icons/**` — product logos (Self Service+, Jamf Parent, Jamf Teacher, BeyondCorp) and notification icons, downloaded verbatim. | 9 |
| `raw/`               | Source artefacts (`jamf-icons.woff`, the stylesheet, the icon JS chunk) for reproducibility.       | — |
| `manifest.json`      | Machine-readable index: every icon, how it was named and how confident that is, every settings card (title, description, page path, icon, colour), and the colour tokens. | — |
| `contact-sheet.html` | Visual index with a name filter. Serve the folder (`python3 -m http.server`) or open directly.       | — |

All SVGs use `fill="currentColor"` (except the coloured tiles), so they inherit `color` when inlined
in HTML and render black as a plain `<img>`.

## Re-running

```sh
pip install fonttools            # only dependency beyond the standard library
python3 scrape_jamf_icons.py     # defaults: tfproviderdev.jamfcloud.com → this folder
python3 scrape_jamf_icons.py --base-url https://your.jamfcloud.com --out /tmp/icons -v
```

No Jamf Pro credentials are needed — every asset touched is a public static file of the front end.

## How it works

1. `GET /angular/upgrade-module/en/index.html` gives the hashed names of the entry bundle
   (`main-*.js`) and stylesheet (`styles-*.css`).
2. The stylesheet declares the icon font at `/assets/fonts/icons/jamf-icons.woff` and 716 `.icon-*`
   classes. Glyph names inside the font are the real icon names; each glyph is transformed from
   font units (1024 UPM, y-up) into a 24×24 SVG path.
3. `main-*.js` is crawled through its ESM `import` graph (~236 chunks). The chunk containing
   `{height,width,viewBox,path:'<path …/>'}` objects is the inline icon library.
4. `settings.module-*.js` defines every Settings card as
   `cardTitle / cardDescription / cardIcon:{icon:X,color:p.ORANGE}`; the colour tokens
   (`--color-orange-background`, `--color-orange-font`) come from the stylesheet.
5. Any `assets/icons/**.svg` string found in the bundles is downloaded.

### Naming the inline icons

The inline library's export names are minified (`T0 as c`), so real names are recovered from:

- **usage** — identifiers leaked by importing code, e.g. `this.exclamationTriangleOutline = X` or
  Vue `{chevronUpSolid: X}` (62 of 130, `confidence: high`);
- **geometry** — the icon's flattened outline compared with every font glyph on a 16×16 grid plus
  filled-area (outline vs solid), taking the best unambiguous match (68 of 130; `high`/`medium`/`low`
  recorded in `manifest.json` together with the top three candidates).

Icons named `low` are worth a glance in the contact sheet before use; none are unnamed.

### Known quirks

- 10 CSS classes (`arrow-refresh-solid`, `jamf-solid`, `pin-solid`, …) have no glyph in the font, so
  there are 706 files for 716 classes.
- The sidebar "Blueprints" icon is named `blueprints-outline` in Jamf's code but is the
  `adjustments-horizontal-outline` glyph in the font — both files exist.
- The Jamf Pro version is only exposed behind authentication; `manifest.json` records the hashed
  bundle names as the build identifier instead.
